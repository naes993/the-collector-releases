# The Collector

Downloads and the update feed for The Collector, a macOS menu bar app that collects windows from different apps into tabs.

**[Download the latest version](https://github.com/naes993/the-collector-releases/releases/latest)**: unzip it and move The Collector to Applications. It needs macOS 13 or later and Accessibility access (System Settings > Privacy & Security > Accessibility).

Once installed, the app checks for updates by itself once a day, or any time from Check for Updates… in its menu bar menu.

This repository holds only the release zips and `appcast.xml`, the feed the app reads. The app's source code is not here.
